# Station stills

Selected original images and RF evidence from the UFO Files Project field station.

Each session contains up to three representative full-resolution stills, motion-trigger comparison and confirmation images, separate annotated images, RF JSONL, and session metadata. Trigger images are the native camera JPEGs; annotated copies are illustrations of changed regions, not object classifications.

Internet Archive is the primary video destination; session manifests link to its public items and uploaded MP4s. Each Archive item also includes the complete finalized session manifest, selected original stills, motion evidence, RF records, logs, timing files, and a checksum inventory. Original MJPEG video archives and temporary capture segments are excluded. Remote file sizes and MD5 checksums must match, and the MP4 must be publicly downloadable, before verification. Local videos are eligible for cleanup one hour after Archive verification. YouTube is an optional mirror; its upload limits do not block the primary archive. The archived MP4 matches the encoded upload file, which is already a lossy derivative of the camera MJPEG source. Full per-frame JPEG exports are no longer generated automatically. Old exports are pruned only after selected evidence is confirmed in this repository and the video's verified offsite retention window has expired.

The station preserves a 100 GiB local free-space reserve. Upload failures retain local evidence for retry. UTC timestamps use the station clock; HDMI capture latency is not calibrated.

Observations and automatic triggers do not establish a sighting or identify an object.
