# Station stills

Selected original images and RF evidence from the UFO Files Project field station.

Each session contains up to three representative full-resolution stills, motion-trigger comparison and confirmation images, separate annotated images, RF JSONL, and session metadata. Trigger images are the native camera JPEGs; annotated copies are illustrations of changed regions, not object classifications.

Videos are linked in session manifests after verified YouTube processing. YouTube copies are recompressed and are not original-quality backups. Local videos are eligible for cleanup one hour after YouTube verification. Full per-frame JPEG exports are no longer generated automatically. Old exports are pruned only after selected evidence is confirmed in this repository and the video's verified retention window has expired.

The station preserves a 100 GiB local free-space reserve. Upload failures retain local evidence for retry. UTC timestamps use the station clock; HDMI capture latency is not calibrated.

Observations and automatic triggers do not establish a sighting or identify an object.
